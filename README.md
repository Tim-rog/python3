# Лабораторная 3. Каталог объектов (учебные аудитории)

Запуск тестов:  `pip install pytest && pytest -v`

```python
from catalog import Room, Catalog
c = Catalog()
c.add(Room("Л-101", "Большая лекционная", "лекционная", 1985,
           "Главный корпус", 1, 120, ("проектор",)))
c.save("catalog.json")
```
Структура: errors.py (исключения), models.py (Room + __post_init__),
catalog.py (каталог), storage.py (JSON), view.py (read-only view).
Порядок итерации: порядок добавления; после load - порядок в файле. 
Также сдаленны индекс по категории, undo, read-only view, миграция v1->v2,
транзакции с rollback.

Основаная идея лабарторки, которую я для себя подметил это post init, и по сути система,
в которой новый объект датакласса не может быть создан, если он изначально инвалид. Сохраняются только правильные объекты
